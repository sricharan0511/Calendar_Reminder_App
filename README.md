# Calendar & Reminder App

A Python-based Calendar and Reminder application developed as part of my Python Development Internship.

## Project Description

This application displays a monthly calendar and allows users to create and manage reminders for specific dates.

The application provides a simple interface for navigating through months, selecting dates, adding reminders, and deleting selected reminders.

## Features

- Monthly calendar display
- Previous and Next month navigation
- Today button
- Date selection
- Add reminders with time and description
- View reminders for a selected date
- Delete selected reminders
- Reminder data saved for future use
- Simple and user-friendly interface

## Technologies Used

- Python
- Tkinter
- JSON
- Calendar and DateTime modules
